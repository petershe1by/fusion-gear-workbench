# Fusion 齿轮工坊 · Fusion Gear Workbench

Autodesk Fusion 桌面版 Python 附加模块，无第三方依赖。生成的是可加孔、键槽和倒角的 Fusion 实体，不是 STL 网格。


## 安装与打开

1. 解压发行 ZIP 到固定目录，保留其中的 `FusionGearWorkbench` 文件夹，勿重命名或只拷贝单个 `.py`。
2. 在 Fusion 按 `Shift+S`，或从 **设计 → 实用工具 → 脚本和附加模块** 打开管理器。
3. 点击 `+` → **从设备添加脚本或附加模块**，选中包含 `FusionGearWorkbench.manifest` 的文件夹。选中 `FusionGearWorkbench`，点 **运行**。
4. 在 **设计 → 实体 → 创建** 下拉菜单中找 **齿轮工坊 · 生成 / 改参 / 导出**。用**混合设计**并保留参数化时间线；若新文档是零件或装配设计，可在左侧 **文档设置 → 设计类型** 转换为混合设计。

**从旧版更新：**只解压新版不会切换 Fusion 已登记的路径。先保存当前设计，在附加模块管理器里停止旧版并取消 **启动时运行**。然后用新版 `FusionGearWorkbench` 内的文件覆盖 Fusion 当前登记目录里的同名文件，或者移除旧版登记后重新选择新版目录。重启 Fusion，再确认窗口顶部显示 **Peter Shelby**，标题含 **v0.1.4**。已有模型不需要重建。

**0.1.4：**首次开源版本；在附加模块管理器和三个命令面板中加入作者署名。

**0.1.3：**在齿轮组件内创建扫掠路径；蜗杆先沿自身轴线完成分段扫掠，再按 90° 装配位置放置。菜单、命令标题和生成报错显示正在运行的插件版本，便于确认是否仍加载旧版。

**0.1.2：**修正斜齿、人字齿、斜内齿圈及蜗轮蜗杆生成时，子组件中的扫掠轴线缺少装配引用的问题。若仍失败，请保留新弹窗中的步骤名称（例如“扫掠路径”或“绘制齿形”）和参数。

## 先试这个

选择 **直齿圆柱齿轮** → **按分度圆直径** → `48 mm`、模数 `2 mm`、厚度 `8 mm`、孔径 `6 mm`。预计得到 **24 齿、分度圆 Ø48 mm、齿顶 Ø52 mm、齿根 Ø43 mm**。勾选 **生成后导出 STEP**，生成成功后选择保存位置；取消保存不会撤销模型。

参数随齿轮类型和尺寸输入方式变化：直齿不显示螺旋角、蜗轮蜗杆或齿条的输入项；选择斜齿或人字齿后才显示螺旋角和旋向。蜗轮蜗杆还会根据输出选择隐藏不需要的字段。压力角和齿厚减薄量在默认折叠的 **高级参数（可选）** 中。

| 类型 | 输入方式和特有参数 |
|---|---|
| 直齿 / 斜齿圆柱 / 人字齿 | 分度圆、齿顶外径或齿数；斜齿可更改螺旋角 `0–45°` 与左右旋，使用法向模数；人字齿无中央退刀槽 |
| 内齿圈 | 分度圆或齿数，直齿 / 斜齿，齿根以外的径向壁厚；界面区分齿顶直径、齿根直径与外圈实体外径 |
| 直齿锥齿 | 大端分度圆或齿数，输入配对齿数与沿锥面齿宽；固定 90° 轴交角；输出单件近似模型 |
| 蜗轮蜗杆 | 选整组、单蜗轮或单蜗杆；轴向模数、蜗杆分度圆、有齿长度、1–4 头、旋向；整组按 90° 轴线和理论中心距放置，无运动约束 |
| 直齿齿条 | 目标长度或齿数、齿宽、齿根以下底座高度；齿距 `π × 模数`，两端对称 |

直径、模数和整齿数不能同时任意指定。按直径或长度输入时，面板显示取整后的**实际**尺寸；加工前以实际尺寸为准。`齿厚减薄量` 是单件节线齿厚的减量，不是对装配后实际侧隙的保证。

## 二次编辑与导出

- 保存原 Fusion 设计，或用 **齿轮工坊 · 导出** 选择 **整个设计 · Fusion 原生备份 (.f3d)**。原生模型有草图、拉伸 / 扫掠等特征和插件参数。这个选项保存整个设计，并非只保存所选齿轮；带外部链接的设计建议直接用 Fusion 保存。
- 在原生设计中，运行 **齿轮工坊 · 改参**，在左侧选生成的顶层组件（蜗轮蜗杆组选父组件）。插件读回参数，在原位置新建一个组件；默认隐藏、**不删除**旧组件。手工增加的键槽、倒角、外部引用、关节不会复制到新版本，建议先定齿轮参数再加这些特征。
- `.step` / `.stp` 能重新导入为实体并做切孔、倒角等编辑，但不会保存原 Fusion 时间线或插件参数。需要后续改模数、齿数或螺旋角时，**STEP 和原生文件都留一份**。

## 工程限制

- 圆柱齿和内齿的渐开线用拟合样条表示，基圆以下采用径向延伸；不包含真实滚刀根切、齿根过渡圆角、变位或修形。
- 直齿锥齿轮是等比例缩放放样；蜗杆为轴向梯形近似，蜗轮是圆柱斜齿近似，**不是滚刀包络蜗轮**。尤其不要把锥齿/蜗轮模型直接当精密传动加工数据。整组未校核干涉、接触斑点、强度、材料或加工公差。
- 建议先用默认参数生成，确认尺寸和实体后再逐项改动。大齿数、宽齿、高螺旋角和多圈蜗杆消耗更多计算时间；生成失败应阅读 Fusion 的错误提示再调整参数。

## 验证

普通 Python 中运行 `python -B -m unittest discover -s tests -v`，不用安装 Fusion 即可检查几何及参数面板的字段切换逻辑。`tests/fusion_smoke.py` 可在 Fusion 的 Python 控制台里执行，使用独立临时设计检查扫掠实体和插件参数。设置 `verify_step=True` 可检查斜齿、人字齿和蜗轮蜗杆组的 STEP 导出与重新导入。报告写入 `tests/fusion-smoke-result.txt`。
